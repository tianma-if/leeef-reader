## 描述

Leeef Reader 是一款离线优先、由你掌控数据的跨端电子书阅读器。无需注册即可导入书籍、整理书架并开始阅读；需要跨设备使用时，可连接你自己的 S3 或 WebDAV 存储。

【多格式书库】
支持 EPUB、PDF、TXT、MOBI、AZW3 与 FB2。可从文件或系统分享导入书籍，自动提取封面、标题与作者，并通过书架、标签、筛选和排序管理收藏。

【专注阅读】
移动端支持交互式仿真翻页，也可选择滑动、无动画或连续滚动。字号、行距、边距、主题、明暗模式和中英文显示均可调整。

【书摘、笔记与回顾】
添加书签、高亮和笔记，按书籍或时间集中整理，并可导出为 Markdown、TXT 或 CSV。阅读统计帮助你回顾时长、连续阅读和完成进度。

【AI 与云存储由电脑配置，手机扫码同步】
可在电脑上连接你自己的对象存储和 AI 服务，用于跨设备同步、划词解释、翻译、章节总结和阅读问答。iOS 不提供对象存储、AI 或云端 TTS 的地址、密钥或服务商填写入口；在电脑上配置后，通过扫描配对二维码或云同步到达手机。

【自己的云，自己的数据】
Leeef 默认只在本地保存数据，不设强制账号。可选的 S3/WebDAV 同步用于在 iOS、Android、macOS 与 Windows 之间同步书籍、进度、书摘和书架。

部分在线功能需要网络连接。S3/WebDAV 由你自行提供存储；存储与 AI 凭据在桌面端配置后同步，不在 iOS 应用内购买或填写。

## 审核备注

应用无需账号即可使用。首次进入完成三页引导后，点“导入书籍”并从“文件”选择 EPUB/PDF/TXT/MOBI/AZW3/FB2 即可阅读。iOS 不提供对象存储、AI 或云端 TTS 的 API Key / 服务商配置界面；这些设置在电脑上完成，经扫码配对或云同步到达手机。审核无需配置第三方 AI 或云存储。S3/WebDAV 和 OPDS 为可选功能，不影响核心离线阅读。
