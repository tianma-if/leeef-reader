# 阅读产品改进：开发与验收记录

状态：工作区实现，尚未发布；没有修改版本号或启动发布流程。

## 已实现

- 配置之外的书库同步：S3/WebDAV 后端复用现有配置；默认关闭书库上传，需在设置中主动开启。书籍、封面、书摘、书签、分类、标签、进度和时长使用同一可移植记录格式。文件上传前加密，下载后校验 SHA-256；数据库合并使用事务。
- 同一文件分别导入不同设备后按哈希合并，不更换本机书籍 ID。关系删除保留墓碑。进度使用最新位置，正在阅读时提供接续提示。替换的书摘与进度保留本机历史记录表。
- `.leeef-backup` 本地书库备份：Argon2id + AES-256-GCM，含书籍、封面及上述阅读数据。恢复前验证密码、对象哈希并预览数量；可合并并保留较新记录，或选择以备份中的匹配记录为准。后者可用于恢复误删笔记和旧进度。本机独有记录保留。
- `.leeef-recovery` 仍单独负责同步空间密钥和服务配置；书库备份不包含凭据或本机未保存为笔记的 AI 对话。
- 选区 AI：解释、翻译、概括、追问、停止、重试、原文跳转、将对话保存为书摘笔记。复用用户设置的模型与接口，选区助手没有修改书库的工具。完成的对话保存在本机 WebView 存储；保存为笔记后可随书库同步和备份。
- 批量导入逐本处理并展示进度；单本失败不会停止其余文件，保留失败列表供重试。修复选择文件后提前清空 FileList 的问题。
- 阅读天数兼容 Unix 秒与 ISO 日期，按设备本地日期归类。阅读器加载完成才开始计时，后台暂停，每 30 秒及离开时保存；失败时保留本次计时器的未保存时长供后续检查点重试。
- 同步文案、配置恢复包名称和 README 中统计能力描述与实现对齐。

## 明确边界

- 书库备份当前通过文本文件桥传输，书籍与封面总量上限 128 MiB；超过时明确失败，不生成截断备份。大书库的流式归档是后续工作。
- 同步文件当前整文件加解密、自动下载；无断点续传、按需下载或远端存储清理。整条记录按版本合并，尚无图形化冲突版本管理。
- 被杀进程之前尚未提交的时长检查点可能丢失；不能据此声称异常退出时零丢失。旧统计数据中虚增的时长不会自动修正。
- 选区 AI 仅看到选中的文本，不代表已经阅读整本书；单次选区限制 16,000 字符。模型输出质量取决于用户配置服务。
- 当前源码不代表商店/GitHub Release 已交付；没有发布、安装或覆盖开发者现有应用。
