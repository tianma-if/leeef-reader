# 阅读产品改进：开发与验收记录

状态：随 v2.6.0 发布。书库同步默认关闭，需在设置中主动开启。

## 已实现

- 配置之外的书库同步：S3/WebDAV 后端复用现有配置；默认关闭书库上传，需在设置中主动开启。书籍、封面、书摘、书签、分类、标签、进度和时长使用同一可移植记录格式。文件上传前加密，下载后校验 SHA-256；数据库合并使用事务。
- 同一文件分别导入不同设备后按哈希合并，不更换本机书籍 ID。关系删除保留墓碑。进度使用最新位置，正在阅读时提供接续提示。替换的书摘与进度保留本机历史记录表。
- `.leeef-backup` 本地书库备份：Argon2id + AES-256-GCM，含书籍、封面及上述阅读数据。恢复前验证密码、对象哈希并预览数量；可合并并保留较新记录，或选择以备份中的匹配记录为准。后者可用于恢复误删笔记和旧进度。本机独有记录保留。
- `.leeef-recovery` 仍单独负责同步空间密钥和服务配置；书库备份不包含凭据或本机未保存为笔记的 AI 对话。
- 选区 AI：解释、翻译、概括、追问、停止、重试、原文跳转、将对话保存为书摘笔记。复用用户设置的模型与接口，选区助手没有修改书库的工具。完成的对话保存在本机 WebView 存储；保存为笔记后可随书库同步和备份。
- 批量导入逐本处理并展示进度；单本失败不会停止其余文件，保留失败列表供重试。修复选择文件后提前清空 FileList 的问题。
- 阅读天数兼容 Unix 秒与 ISO 日期，按设备本地日期归类。阅读器加载完成才开始计时，后台暂停，每 30 秒及离开时保存；失败时保留本次计时器的未保存时长供后续检查点重试。
- 同步文案、配置恢复包名称和 README 中统计能力描述与实现对齐。
- 同步状态中心：展示配置、检查书库、上传、发布更新、读取其它设备、下载与合并阶段；文件传输按对象计数（包含封面），显示当前书名、完成数与剩余数。展示待发布书库记录、最近尝试和成功时间，失败保留阶段与文件并提供重试；最近完成的结果保存到本机，重启后可见。
- 历史版本与误删恢复：设置 → 设备配对与状态 → 历史版本与误删恢复。按书摘/笔记、阅读位置筛选，每页 30 条，可对照所选版本与当前版本。恢复在同一事务内校验预览对应的当前版本，遇到新修改时拒绝覆盖；成功后使用新的本机版本同步，保留替换前内容。
- 本机书摘编辑、删除和阅读位置更新会保留前一版本，远端落败版本也保留。升级时收录旧客户端仍留在本机数据库里的已删除书摘；历史所属书籍已删除时，先恢复或重新导入书籍。

## 明确边界

- 书库备份当前通过文本文件桥传输，书籍与封面总量上限 128 MiB；超过时明确失败，不生成截断备份。大书库的流式归档是后续工作。
- 同步文件当前整文件加解密、自动下载；无断点续传、按需下载或远端存储清理。整条记录按版本合并；历史窗口支持书摘与阅读位置，不提供逐字段自动合并。
- 历史版本仅保存在本机，不随同步或书库备份归档传输；其它设备能收到恢复后的当前记录。无法找回从未保留且数据库中已不存在的内容。当前不自动清理历史。
- 同步进度是当前阶段的文件数量，不是字节级进度；准备阶段的文件检查仍可能耗时。最近结果仅保存已结束的尝试，进程中途退出后显示上次已结束的结果。
- 被杀进程之前尚未提交的时长检查点可能丢失；不能据此声称异常退出时零丢失。旧统计数据中虚增的时长不会自动修正。
- 选区 AI 仅看到选中的文本，不代表已经阅读整本书；单次选区限制 16,000 字符。模型输出质量取决于用户配置服务。
- 发布说明以 GitHub Release v2.6.0 为准。开发记录里的限制仍然有效。

## 验证

- 前端回归覆盖日期归类、后台暂停/检查点重试、批量导入失败隔离、AI 可见内容保存与本机历史解析。
- Rust 回归覆盖独立导入去重、分类/标签删除传播、回看位置同步、事务回滚、文件校验、密码保护备份与误删恢复。
- 使用本地模拟 WebDAV 服务和两份独立数据库验证加密文件上传、缺文件重试、书籍/封面下载、书摘修改与删除、双向进度同步。
- 使用 Codex 内置浏览器、测试 IPC 和本地模拟 OpenAI 兼容服务验证设置展示、AI 回答、保存笔记、引用跳转回调和重新打开对话。没有使用真实凭据、真实书籍或调用付费模型。此项不替代原生端到端测试。
- 未执行 Android/iOS 真机回归，未使用 Android 模拟器；未对用户的真实 S3/WebDAV 存储做写入测试。
