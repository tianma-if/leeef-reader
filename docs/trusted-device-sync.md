# 可信设备与配置同步

更新日期：2026-08-30

## 产品模型

界面只展示“我的同步设备”。内部使用一个 `spaceId` 标识同一套书库和信任边界；第一版每台设备只加入一个同步空间，不提供多空间切换。

对象存储、WebDAV、AI、TTS、代理和同类服务凭据只在桌面端配置。手机设置页提供扫码配对、自动同步开关和只读状态，不提供这些凭据的填写界面。

任意已有可信设备都可以生成一次性配对会话。新设备与其连接同一局域网并输入配对码后，自动接收同步空间密钥、同步后端配置、AI/TTS/OPDS 凭据和阅读配置；二维码扫描是这条配对链路后续补充的输入方式。

## 配对协议

1. 已有设备生成 12 位无歧义随机码、临时 X25519 密钥和 5 分钟会话。
2. 新设备通过 UDP 广播发现会话，再与响应地址直连。配对码不以明文写入 HTTP 请求。
3. 双方使用 X25519 共享秘密和配对码经 HKDF-SHA256 派生会话密钥。
4. 配置快照、同步空间密钥和设备清单使用 AES-256-GCM 传输。
5. 配对成功后会话立即关闭，配对码不能重复使用。

局域网配对不依赖 Leeef 账号或 Leeef 云服务。iOS 使用 `NSLocalNetworkUsageDescription` 说明局域网用途；当前 Android target SDK 36 继续使用既有 `INTERNET` 权限。升级到 target SDK 37 时需要接入 Android `ACCESS_LOCAL_NETWORK` 运行时授权。

## 持续配置同步

配置以每台设备独立拥有的加密文档保存到同步后端。每个配置项记录修改时间和修改设备，冲突时确定性选择最新版本。包括凭据在内的配置离开设备前会加密；当前 Tauri 客户端仍将设置保存在本地应用数据库中，迁移到系统安全存储属于后续安全加固项。

Tauri 客户端在设置保存后立即调度同步，并在应用启动、网络恢复、回到前台和每 15 分钟执行一次兜底同步。它不是依赖桌面在线的局域网推送：配对结束后，两台设备分别通过已配置的 S3 或 WebDAV 后端交换加密配置文档。离线修改会保留本地版本，恢复联网后继续合并。

默认同步：

- 阅读排版、主题、语言及交互偏好；
- S3 与 WebDAV 地址、账号和访问凭据；
- AI Provider、模型、Prompt、Tools 和 API Key；
- TTS 服务配置和 API Key；
- OPDS 目录及密码。

始终仅本机保存：

- 设备 ID、设备私钥和同步空间主密钥；
- 本地书籍目录、数据库迁移状态；
- 桌面窗口位置、开发者状态和缓存；
- 仅含本地文件路径的阅读背景图片。

## 设备撤销

撤销设备会写入加密撤销记录，并创建下一密钥 epoch。新组密钥分别通过仍可信设备的 X25519 公钥封装，旧设备没有对应信封，无法获得或解密后续配置。密钥轮换文档使用旧组密钥认证，条件写入避免并发撤销覆盖同一 epoch。

设备撤销不能自动吊销第三方服务已经签发的共享 S3/WebDAV 凭据。设备确实丢失时，用户仍应在对应服务端轮换凭据，阻止该设备继续访问既有书籍对象。

## 当前边界

- 配对发现仅覆盖同一局域网，尚未提供二维码直连或跨网络中继。
- 至少保留一台可信设备即可恢复新设备；所有设备同时丢失时尚无独立恢复码。
- 共享目录路径属于本机配置，新设备需要自行选择可访问路径。
