## Default Permission

Native capture used by mobile slide turns

#### This default permission set includes the following:

- `allow-capture-webview-region`
- `allow-set-cover-progress`
- `allow-uncover-webview`
- `allow-probe-webview-ready`
- `allow-pick-books`
- `allow-save-text-file`
- `allow-check-mobile-update`
- `allow-start-mobile-update`
- `allow-complete-mobile-update`
- `allow-open-mobile-store`
